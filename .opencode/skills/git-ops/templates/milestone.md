# Milestone body template

One milestone per sub-phase. Title is always `Phase X.Y`. Body follows this exact structure:

```md
**Title**
[Sub-phase title from the roadmap, e.g. "Migrate scraping to the PHP DOM extension"]

**Parent Phase**
[Phase X — the phase this sub-phase belongs to, from the roadmap]

**Description**
- [Implementation note bullet from the roadmap sub-phase entry]
- [Another note bullet]
- [All bullets from the sub-phase entry, copied]

**Done When**
[The sub-phase's "Done when" definition, copied from the roadmap]
```

Rules:
- Copy the Description bullets and Done When text from the roadmap sub-phase entry — do not reword them.
- If a milestone for this sub-phase already exists, reuse it; do not create a duplicate.
